# Canvas em IHC

Em IHC e design, um canvas é uma ferramenta visual de uma só página, dividida em blocos temáticos, usada para organizar, discutir e comunicar ideias de forma rápida e colaborativa. Em vez de longos documentos, o canvas reúne em um quadro único os elementos essenciais de um problema, produto ou projeto.

A ideia vem do Business Model Canvas (Osterwalder), mas foi adaptada para várias necessidades em design de interação e experiência do usuário.

## Características
Visual: blocos preenchidos com post-its ou texto curto.
Colaborativo: feito em grupo, em oficinas (workshops), com design, desenvolvimento e negócio.
Sintético: força a objetividade e a priorização.
Iterativo: é revisado conforme se aprende mais sobre os usuários.
Principais tipos usados em IHC
Canvas	Para que serve	Blocos típicos
Business Model Canvas	Entender o modelo de negócio	Proposta de valor, segmentos de clientes, canais, receitas, custos
Lean Canvas	Validar ideias de produto/startup	Problema, solução, métricas, vantagem competitiva
Value Proposition Canvas	Alinhar produto às necessidades do usuário	Tarefas do cliente, dores, ganhos / produtos, aliviadores de dor, criadores de ganho
Persona Canvas	Descrever usuários	Perfil, objetivos, dores, comportamentos, contexto
Empathy Map Canvas	Compreender o usuário	Pensa e sente, vê, ouve, diz e faz, dores, ganhos
Canvas de Projeto (Project Model Canvas)	Planejar projetos	Justificativa, objetivos, partes interessadas, riscos, entregas
Canvas de Proposta de Interação / MPIu+a e similares	Estruturar decisões de design de interface	Usuários, tarefas, contexto, requisitos, soluções
