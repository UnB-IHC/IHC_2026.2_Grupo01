# Guia de Acessibilidade Digital – Grupo 01 (IHC 2026/2)

Projeto da disciplina **Interação Humano-Computador (FGA0173)** da Universidade de Brasília (UnB), sob a orientação da professora Dr.ª Rejane Maria da Costa Figueiredo.

**Site:** [unb-ihc.github.io/IHC_2026.2_Grupo01](https://unb-ihc.github.io/IHC_2026.2_Grupo01/)

## O que tem neste repositório

- **Guia de Acessibilidade Digital:** checklists práticos de Gestão de Projetos, Design, Desenvolvimento e Conteúdo, baseados na WCAG, na ABNT NBR 17225 e nas 10 heurísticas de Nielsen.
- **Avaliação do site [Nota Legal DF](https://www.notalegal.df.gov.br/):**
  - inspeção com os checklists do guia e as ferramentas WAVE, ANDI e axe DevTools;
  - teste de usabilidade com uma usuária real, pensando em voz alta, com o questionário SUS;
  - recomendações priorizadas e conclusão.
- **Fundamentos de UX:** heurísticas de Nielsen, personas, jornadas, blueprint, canvas, mapeamento de experiências e design empático, todos aplicados ao Nota Legal.

## Como rodar o site localmente

Com o Python instalado, na pasta do repositório:

```bash
python -m pip install mkdocs mkdocs-material
python -m mkdocs serve
```

O site abre em `http://127.0.0.1:8000/IHC_2026.2_Grupo01/`. A cada push no branch `main`, o GitHub Actions publica o site no GitHub Pages.
