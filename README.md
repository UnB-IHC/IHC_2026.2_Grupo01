# Grupo 1

## Introdução

Este repositório fornece um checklist prático de acessibilidade para projetos de desenvolvimento de software, abrangendo áreas como desenvolvimento web, design, geração de conteúdo e gestão de projetos.

O projeto foi desenvolvido no âmbito da disciplina de Interação Humano-Computador (IHC) na Universidade de Brasília (UnB), sob a orientação da professora Dr.ª Rejane Maria da Costa Figueiredo.
